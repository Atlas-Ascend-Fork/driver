## 章节结构对照表

| 节号 | 标题 | 内容 |
|------|------|------|
| §1 | 功能点清单 | 功能点×类型（新增/扩展）×说明 |
| §2 | 接口规格 | 每个接口完整规格（参考存量 spec.md 格式）：函数原型+参数+返回码+约束矩阵+调用路径+前置条件+注意事项 |
| §3 | 支持场景 | 芯片型号×互联方式×部署形态×支持功能点 |
| §4 | 不支持场景 | 场景×原因 |
| §5 | 复用接口补充说明 | 复用的已有接口规格要点（返回值语义+线程安全+局限性） |
| §6 | 消息规格 | 如有新增消息：枚举+结构体+约束矩阵；如无：保留标题写"本次变更无新增消息。" |
| §7 | 文件索引 | 文件路径×变更类型×变更内容 |

## 写作规则

| 规则 | 说明 |
|------|------|
| **定位：功能规格说明** | 明确有哪些功能、哪些支持/不支持、接口详细规格 |
| **参考存量格式** | 接口规格参考存量 spec.md 格式（函数原型+参数+返回码+约束矩阵+调用路径+前置条件+注意事项） |
| **新增接口完整规格** | 新增接口给出完整规格说明 |
| **复用接口补充说明** | 复用接口列出规格要点，补充存量 spec.md 中未覆盖的内容 |
| **支持/不支持场景明确** | §3 支持场景 + §4 不支持场景，读者一眼知道功能边界 |
| **消息规格可选** | 有新增消息时填写 §6，无新增时保留标题写"本次变更无新增消息。" |
| **file:line 标注** | 所有接口声明标注 `{文件名}:{行号}` |
