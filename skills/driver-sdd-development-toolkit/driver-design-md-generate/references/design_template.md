# 子模块 design.md 模板规范

> 本文件定义子模块 design.md 的统一模板。
> 所有子模块文档必须使用本模板的章节结构，确保与已有文档一致。

## 模板选择规则

| 模块类型 | 模板 | 选择条件 |
|---------|------|---------|
| 复杂子模块 | 复杂8节模板 | 源码 > 500 行，或有复杂数据结构/算法 |
| 简单子模块 | 简单8节模板 | 源码 ≤ 500 行，逻辑简单 |

> 不确定时用简单8节模板，宁简勿繁。

## 复杂8节模板（≥200行）

```markdown

# {子模块名} 设计文档

> **分类**: {分类} | **部署**: {用户态/内核态/混合} | **源码**: `{源码路径}` ({行数}行)
>
> **模型**: {model_id} | **日期**: {date} | **Git**: {git_hash} ({branch})
>
> **源码验证声明**: 本文档所有函数引用、结构体字段、行号均经 Grep/Read 从源码验证。

---

## 1. 软件功能

{2-3句话说明子模块核心职责}

**实现文件**:

| 文件 | 行数 | 功能 |
|------|------|------|
| `{file}` | {N} | {功能} |

## 2. 对外接口

{子模块对外暴露的接口函数}

| 接口函数 | 声明位置 | 功能 |
|---------|---------|------|
| `{func}(...)` | `{file}:{line}` | {功能} |

## 3. 依赖关系

### 3.1 依赖的子模块

| 子模块 | 调用接口 | 用途 |
|--------|---------|------|
| {子模块名} | `{func}` ({file}:{line}) | {用途} |

### 3.2 被依赖关系（被谁调用）

| 接口函数 | 主要调用者 | 用途 |
|---------|-----------|------|
| `{func}` | {调用者1} / {调用者2} | {用途} |

> 多个调用者用 `/` 分隔合并到一行，不逐个列出调用位置（文件:行号）。调用位置在 CK1V_SCAN 验证阶段记录，不写入最终文档。

## 4. 模块总体结构

{模块内部结构、关键文件关系、核心流程}

> 子模块级文档**不使用 Mermaid 图**，用文字+列表描述内部结构和调用链。Mermaid 图仅用于模块级（如 4_share/share_design.md）文档。

## 5. 关键结构体

```c

```text

> 无结构体时**保留本节标题**，内容写"本模块无关键结构体。"，不删除章节，不改变后续编号。

## 章节结构对照表

| 节号 | 标题 | 内容 |
|------|------|------|
| §1 | 软件功能 | 核心职责 + 实现文件表 |
| §2 | 对外接口 | 对外暴露的接口函数表 |
| §3 | 依赖关系 | 依赖的子模块 + 被依赖关系（三列简表，不列调用位置） |
| §4 | 模块总体结构 | 内部结构 + 关键流程（文字描述，不用 Mermaid） |
| §5 | 关键结构体 | 核心数据结构（无则保留标题写"本模块无关键结构体。"，不删除章节） |
| §6 | 关键设计要点 | 设计决策 + 算法说明 |
| §7 | 相关文件索引 | 只列本子模块目录下的文件（不列依赖模块/调用者文件） |
| — | 变更记录 | 版本历史 |

## 写作规则

| 规则 | 说明 |
|------|------|
| **源码是唯一验证标准** | 参考文档辅助理解，所有声明必须从源码 Grep/Read 确认 |
| **file:line 标注** | 所有函数引用标注 `{文件名}:{行号}` |
| **0 `[待验证]`** | 仅允许 `[未验证]`（源码中找不到时） |
| **禁止伪造** | 禁止猜测函数名/行号/结构体字段/算法逻辑 |
| **调用者分析** | 在整个模块代码库中 Grep 搜索调用者（范围见 knowledge.md §2） |
| **描述用中文** | 代码符号保持英文 |
| **task=进程** | 如适用，task 即进程 |
| **章节结构必须一致** | 所有子模块文档使用本模板的 §1-§7 章节结构，不得自创章节名 |
| **§3.2 被依赖关系简化** | 用三列简表（接口函数 \| 主要调用者 \| 用途），多个调用者用 `/` 分隔合并到一行，不逐个列出调用位置（文件:行号） |
| **§4 不用 Mermaid** | 子模块级文档不使用 Mermaid 图，用文字+列表描述内部结构和调用链。Mermaid 仅用于模块级文档 |
| **§5 省略规则** | "省略"= 保留章节标题 + 写"本模块无XX。"，**不删除章节，不改变后续编号** |
| **§7 只列本模块文件** | 相关文件索引只列本子模块自己目录下的文件（.c/.h/.cmake 等），不列依赖模块的文件和调用者的文件 |
